# Van Gogh — гостиница в Кызылорде

Адаптивный лендинг гостиницы: категории номеров, цены, 29 фотографий, галерея и запрос бронирования через WhatsApp.

## Локальный запуск

Требуется Node.js 18 или новее. Зависимости не нужны.

```sh
npm start
```

Откройте http://127.0.0.1:4173.

Готовый сайт находится в `dist/` и подходит для любого статического хостинга.
`rooms.json` содержит исходные сведения из 2ГИС; `node build.cjs` пересоздаёт HTML и данные номеров, при необходимости скачивает фотографии.

Цены получены из карточки 2ГИС, обновлённой 6 октября 2026 года. Бронирование подтверждает администратор. Фотографии и данные: https://2gis.kz/kyzylorda/firm/70000001063235573.
